添加画师到本地库
在「搜索关键词」中输入画师名、别名或 Danbooru 画师 tag。服务端会在 D 站 画师分类中匹配，并用 posts.json 确认至少有一条可预览作品后才写入本地库；否则拒绝添加。若本地库中已有同一画师（空格与下划线视为相同、忽略大小写），则不会重复添加。遇 403/限流时请在节点「D站账号」填写登录名与 API Key（画廊会随 iframe 同步到本页请求）。
